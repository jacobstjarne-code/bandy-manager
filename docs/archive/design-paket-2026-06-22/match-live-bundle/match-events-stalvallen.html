Match-händelser · Stålvallen-vokabulär

Fyra interaktiva spelmoment — hörna, frislag, straff, kontring — översatta till tavlans språk. Ramverket (LED-tag, läder-panel, koppar-kant, monospace-timer) sitter; den nya delen är att själva spelsituationen visas schematiskt på en taktiktavla i panelen, så att man läser av läget, inte bara väljer mellan tre etiketter. Färgerna (röd / amber / grön) återanvänder LED-paletten — taktiktavlan är samma familj som matchuret.

Vad som är nytt:
  • Schematisk taktiktavla i varje event-panel — målbur, MV, försvarare, mur, zoner, anfallarnas rusningar — ritad som en mörk LED-display, inte som en grön plan. Tre färger: röd LED = motståndare, amber LED = egna spelare, grön LED = valda zoner/banor.
  • Hörna: kortsida + bås, 3 zoner (NÄRA / MITT / BORTRE) med träffprocent, kurvad pass-pil från flaggan, framåtanfallarnas rusningar markerade med nummer.
  • Frislag: målbur uppe, mur som röda block, distans-linje, tre färdiga banor (skjut / chip / kort) med vald grön och övriga dimmade.
  • Straff: målbur framifrån, 6 zoner (V / M / H × HÖGT / LÅGT) med procent, MV blockerar mitten visuellt, skottbana till vald zon.
  • Kontring: planhalva, försvarare som backar, löparen pulserar, tre val-banor (bryt / spela av / bygg upp) ritade som riktiga linjer på planen.
  • Sub-val (leverans / höjd / val) behåller samma monospace LED-knappar som tidigare — grön = aktiv, dämpad amber = inaktiv.
