# Copy-pool — NU-stiltje (C-N1)

Två pooler för stillness-rendering på NU-fliken. Code slumpar utan upprepning per spelinstans. Båda är **enbart narrativa** — inga osynliga mood-effekter (per Designs öppna fråga Q3, bekräftat av Opus).

**Källor:** `docs/mockups/2026-05-23_design_nu_stiltje.html` + `HANDOFF-C-N1-NU-STILTJE-2026-05-23.md`.

## Bekräftade designval (Designs Q1–Q3 från 2026-05-23, svarade av Opus 2026-05-31)

- **Q1 — stämningskurva alltid eller bara vid variance?** → ALLTID. Förändring över tid är information; konstant linje är också information.
- **Q2 — heritage-rad exakta jubileum eller även ungefärliga?** → ENBART EXAKTA (samma datum, hela år sedan). Sällsynta jubileum är guld; ofta-jubileum blir spam.
- **Q3 — får mikrohändelser ge mood-effekter?** → NEJ. Stannar narrativa. Konsekvent med principen "mjukt och synligt" — inga osynliga konsekvenser.

## Format-anteckning till Code

Vid TypeScript-konvertering: enklast som två `string[]` (stillnessBeatPool, microStillnessPool) i `src/domain/data/`. Senare ev. taggning per kategori (bygd/klubb/väder/övrigt) för viktning per kontext, men inte i V1 — random med no-repeat-tracker räcker.
