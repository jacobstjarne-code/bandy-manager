Designbeslut

Yta: portal-mörk scen (inte ljust kort)

BoardMeeting är en ceremoniell övergång mellan säsonger — samma kategori som ArrivalScene. Den ärver scen-vokabulären (genre-label, setting-prolog, speaker-block, scene-CTA) på mörk --bg-portal. Ett ljust kort hade signalerat "vardags-status", men detta är ett avstamp. Mörk yta = vi stannar upp.

Återanvänt från ArrivalScene-vokabulären

  • .genre — "⬩ STYRELSEMÖTE ⬩" diamantflankerad genre-label
  • .setting — Georgia-italic prolog som sätter rummet (kaffe, bakelser, kall lokal)
  • .speaker-name + .speaker-line — Margareta talar, samma som scen-dialog
  • .scene-cta — mörk-yta-knapp, gold-variant vid bra säsong

Nya block för BoardMeeting

  • Eval-block — förra säsongens måluppfyllelse. ✓/✕ per mål, stripe-färg per utfall (cold neutral / success / danger).
  • Fin-block — kassa + budget, med trend-sparkline (score-system) som visar riktning.
  • Goals-block — nya mål. Stretch-mål får gold-stripe + 🏆. Vanliga accent-stripe.

Hur tonen skiljer sig

LägeSettingTitelCTA
A First-timeTar av kavajen — informellt"Ett år bakom oss."Copper
B BraBakelser, ler innan hon talar"Det gick bättre än vi vågade hoppas."Gold
C DåligKall lokal, bläddrar för länge"Vi måste prata om året som gick."Copper

Tonen sitter i settingen (rummets detalj) och titeln — inte i fanfar eller röd-larm. C säger "ingen letar syndabockar" — allvar utan klagomål, exakt som briefen ber om. Gold-CTA reserveras för B (samma magi-princip som SM-final).

"Nya mål" visualisering

Mål som goal-cards med ikon + huvudtext + italic-motivering. Stretch-mål (SM-guld i B) får gold-stripe så det syns att det är en högre ambition, inte ett baskrav. I C är båda målen defensiva (🛟 trygg mitten, 💰 positiv kassa) — inga stretch.

Bandysvensk understatement

Ingen cinematik. Margareta säger "då pratar vi om något" (B) istället för "vi siktar på guldet!". C säger "vi får dra ner och bygga om" istället för dramatik. Settings bär känslan genom konkret bild (kall lokal, bakelser) — visa, inte berätta.

Öppna frågor till Opus

  • Speaker — alltid ordföranden (Margareta), eller varierar talaren per klubb (boardPersonalities)? Mocken antar ordförande; lätt att parametrisera.
  • Eval-block — visa alla mål eller bara de viktigaste 3? Föreslag: max 3, det viktigaste först.
  • Copy-pooler per läge (A/B/C) levereras av Opus — settings + titel + speaker-line + goal-motiveringar.
