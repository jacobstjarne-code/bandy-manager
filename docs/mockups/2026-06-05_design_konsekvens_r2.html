R2-1 · Rubrik-kalibrering

  • Instanser konformar till befintliga roller — ingen storleks-flora.
  • EN ny: .h-display-hero = Georgia 52px / 900, letter-spacing −1px. Endast säsongsavslut + seger-hjälte. Täcker 44–64px-avvikarna.
  • Ny .h-eyebrow = 11px / letter-spacing 3px / uppercase / accent. Skild från .h-label (8/2px) — den återkommande "ÅRSBOK"-eyebrown får egen roll.
  • SeasonSummary h1 900→.h-display-hero. BoardMeeting 23→28, 12.5→13 (konforma till .h-scene-*).

R2-2 · Hjälte-CTA

  • Sanktionera .btn--hero: radius 14, padding 17×22, 16px/800, glow (color-mix(--accent 40%)). .btn--hero.gold för SM/cup-seger.
  • Domängräns (DB-2-anda): säsongsslut, seger, cup. Aldrig vardag — vardags-CTA förblir .btn-primary.
  • Radius-12-avvikelsen stängd: hero→14, allt annat→8. Dela/Historik → .btn-outline (accent), Historik slutar vara grå.

R2-3 · Åldersband (DB-5-familjen)

  • En chip-form: radius 99, fyllning color-mix … 8%, kant … 40%. Utvecklas=--cold, Peak=--success, Avtar=--text-muted.
  • --ice + radius-4 + grå-fyllning dras tillbaka. Guld aldrig (DB-2). Cold/muted inom squad-undantaget.
  • Åldersband är chip, inte stripe — stripen bär actionable state (DB-5), bandet bär konstant ålder.

Öppna flaggor till Opus

  • R2-1: 900-vikt finns Georgia ej på alla OS — fallback till 800 + letter-spacing −1px ger nära nog tyngd. Bekräfta acceptabelt.
  • R2-3: pill-fyllning 8%/40% avviker lätt från DB-1-kanon (6%/30%) — pill tål mer kontrast vid liten yta. Antingen ratificera pill-undantaget eller dra till 6/30.
