Manager-karaktären — design-rationale

Vad mocken introducerar

  • Manager-profil-card i ClubScreen "Tränare"-tab (NY tab) — stats, burnout-sparkline, bio, kontraktsstatus.
  • Burnout-meter mätt över tid via sparkline. Färger: success (frisk) → warm (märkbar) → danger (hot).
  • BurnoutMark i Portal — pendant till PhaseMark/SpectatorMark/AnniversaryMark men danger-tonad. En gång per säsong vid trigger.
  • Coach-rivalry-block — H2H-rekord per motståndartränare med karaktärs-citat.
  • Tränaravtal — du har ett kontrakt som löper ut. Förlängning förhandlas. Anbud från andra klubbar.

Datakrav

Ny domän-entity: ManagerProfile med:

  • name, age (åldras 1/säsong)
  • hometown, familySituation (driver bio-narrativ)
  • contractUntilSeason, monthlySalary
  • burnoutHistory: number[] (sparkline-datapunkter, en per omgång)
  • careerRecord: { wins, draws, losses }
  • coachRivalries: Record<clubId, RivalryRecord>

Burnout-mekanik

Per omgång beräkna burnout-värde (0-100). Faktorer:

  • Decision-fatigue-meter (R1)
  • Förluster senaste 3 omg (+10 per förlust)
  • Pendingar i inkorgen (+2 per oläst)
  • Återhämtning vid vinst (−5)
  • Drift mot 0 per omg utan tryck

När burnout ≥ 70 i 2+ omgångar i rad → BurnoutMark triggas vid nästa Portal-render. Konsekvens: team-mood −10 nästa match, eller acceptera "paus-omg" (Sture skippar press, missar event).

Tränaravtal

Vid säsongsslut (eller 3 omg innan utgång): styrelsen tar beslut om förlängning. Faktorer:

  • Tabellresultat senaste 2 säsonger
  • Burnout-medel (high = mindre attraktivt)
  • Patron-relation
  • Slumpat 20-40% chans på utbud från annan klubb (skapar förhandlingsläge)

Om kontraktet inte förlängs: GameOver i slutet av säsongen. Spelaren får välja om de fortsätter på annan klubb eller startar nytt.

Coach-rivalry

Generera 1 fiktiv tränare per AI-klubb vid season start. Karaktärs-data (namn, ålder, hometown, signature-style). H2H-rekord byggs över tid. Citat-pool per tränare-personlighet (3-4 typer: heders / kall / passiv-aggressiv / ödmjuk).

Designval öppna

  • Q1: Får manager-bio förändras över tid (livsförändringar — familjen flyttar, hemorten byts)? Eller är det statisk?
  • Q2: Burnout = mjuk konsekvens (mood-effekt) eller hård (GameOver-risk)?
  • Q3: Coach-rivalry-citat — Opus genererar pool eller blir det LLM-genererat per session?
  • Q4: När du startar S3 — ska du se dig själv åldras? Subtila förändringar i bio över säsonger?
