Audit-fynd över hela trupp-systemet

🟥 NU-vy · 4 sektioner men ingen hierarki
Sektionerna har platt struktur. Hjälp spelaren förstå hur trupp mår på 1 sek: Squad-pulse-sparkline överst som hero.
🟥 TAKTIK · ingen kemi-synlighet
chemistryStats finns i state men visas inte. Kemi-par-rader med sparkline över tid aktiverar systemet.
🟧 NU · status-cards utan portrait
Idag: bara text. Förslag: portrait + chip + position. Konsistens med Trupp-vy.
🟧 TRUPP · summary-card statisk
Toppskytt/assist/betyg är skytteliga, inte trend. Lägg sparkline + visa portrait för stjärnan.
🟧 Modal · 832 rader, ingen tab-struktur
Stats, karriär, skador, relationer huller om buller. Tabs separerar + hero-block med stor portrait + CA-trend.
🟨 Filter/sort · chip-konsistens
Filter använder btn-copper/btn-ghost. Sort använder annan stil. Båda till chip-system som matchar trupp-rader.
🟨 Pitch · spelarpunkter utan kemi-bevis
Idag: bara position-prick. Förslag: dot-färg per kemi-state (success/warn/danger) ger snabb-skanning av lineup-styrka.
💎 Lineup-tabs · bevara
Startelva/Bänken/Reserv-tabs är robusta. Polera bara stilen (chip-konsistens) — behåll mekaniken.
💎 NU-formation-card · bra grund
"Nuvarande vs Rekommenderad" + coach-citat funkar. Förbättring: migrera coach-citat till expandable-area om man vill se argumentet.

Systemförslag — fyra ytor som arbetar tillsammans

Hierarki över trupp-tab

Idag är de tre ytorna oberoende. Förslag: NU = sammanfattning, TRUPP = djup, TAKTIK = relationer. Modal = historik. Varje yta använder samma primitiver (portrait, chip, sparkline, border-stripe).

Designsystem-konsekvenser

PrimitivKällaVar används
Portrait (placeholder)Ny getPortraitPlaceholder()Alla fyra ytor — konsistent
Chip-system (10 varianter)Designsystem-tilläggTrupp-rad, NU-status, Modal-hero, Filter/sort
SparklineScore-systemSquad-pulse, CA-trend, Kemi-trend, Summary-card
Border-stripe per fasDesignsystem-tilläggTrupp-rad, NU-status-card

Portrait-placeholder · övergångsstrategi

  • Idag: getPortraitSvg(playerId, age, position) returnerar genererad SVG. Behåll som fallback.
  • Förslag: Ny getPortraitPlaceholder(player) returnerar gradient-cirkel + initial + state-dot. Mer visuellt bandysvenskt.
  • När riktiga illustrationer landar: Wrappa båda i <Portrait player={p} />-komponent. Switchar källa internt baserat på player.illustrationUrl. Existing code behöver inte ändras.

Spellogik-aktiveringar utöver förra mocken

  • NU-vy: Squad-pulse aktiverar teamFitnessHistory (R1 + C-FT1-data). Lyfter osynlig trötthet till synlig.
  • TAKTIK-vy: Aktiverar chemistryStats som idag är dolt i state. Per-par-sparkline visar trender över omg.
  • Modal: Tab-struktur ("Skador") integrerar Henrik från #5-handoffen — modal-hero visar status-dot för injury, tab visar full historik.
  • Status-dots på portrait: 4 dot-varianter (injury, lobby, national, suspended) ger snabbskannning utan att läsa chips.

Migration · 6 steg

  1. Portrait-placeholder-komponent (~1.5h) — fungerar isolerat, ersätter getPortraitSvg stegvis
  2. Chip-system + border-stripe (~2h) — kosmetisk refaktor av PlayerRow
  3. NU-vy redesign (~2h) — Squad-pulse + status-cards med portrait
  4. TAKTIK kemi-rader (~2h) — läser chemistryStats, sparkline + advice
  5. Modal tab-struktur (~3h) — refaktor av 832-rad-modalen
  6. Summary-card med sparkline (~1h) — sista polering

Total: ~11.5h Code. Inkrementellt, kan delas över 3-4 sprintar.

Designval öppna

  • Q1: Squad-pulse i NU — vad mäter den exakt? Föreslag: viktad sum av fitness × moral × injuries × form. Synlig formel — inga dolda viktningar.
  • Q2: Portrait-status-dot — max ett samtidigt eller stapla? Föreslag: max ett, prioritet injury > suspended > lobby > national.
  • Q3: Kemi-rader — visa topp 3 eller alla? Föreslag: topp 3 + "se alla 28" länk om spelaren vill djuplöda.
  • Q4: Modal-tabs — 4 stycken räcker, eller behövs "Lön/Kontrakt" som 5:e? Föreslag: behåll 4. Lön är del av "Karriär".
