DB-1 · MASTER
Alpha-/tint-systemet
Ratificera color-mix(in srgb, var(--token) N%, transparent) som enda teknik. Fem kanoniska steg per semantisk färg. Hårdkodad rgba() → mekanisk konvertering (Code).
Kanonisk skala — per semantisk färg
6% · tint-bg (kort-fyllning, oläst-rad)
18% · divider / svag linje
30% · border / chip-kant
35% · glow (box-shadow, sparsamt)
55% · halv-fyllning (sällsynt)
5 steg: 6 / 18 / 30 / 35 / 55 %. Ersätter floran 0.04–0.4. Tailwind-rgb (34,197,94 / 239,68,68) tas bort — ej kanoniseras. --success / --danger ersätter.

Beslut i sammandrag — för DESIGN-DECISIONS.md

Pass A — system

  • DB-1: color-mix(in srgb, var(--token) N%, transparent), steg 6/18/30/35/55% (tint-bg/divider/border/glow/fill). Tailwind-rgb bort.
  • DB-4: Pengar=Georgia · Score=ScoreBlock/mono · Statistik=mono · Placering=Georgia display.
  • DB-8: Scrim/fade ja, dekorativ yt-gradient nej, scen-atmosfär sanktionerat undantag.
  • DB-9: 6px→8px (--radius-md). Skala 14/8/3 oförändrad.

Pass B — semantik & score

  • DB-2: Guld = fullbordad seger + bekräftad landslagsmerit. Ej aspiration/pågående. Kontrakt→warm, B-läge/stretch→accent.
  • DB-3: ScoreBlock hero-variant överallt i UI-flöde; ceremoniell Georgia-siffra endast segerscen.

Pass C — komponent & yta

  • DB-5: Stripe=en prioriterad state (skada>moral/lobby>kontrakt>ålder), övrigt chips. Guld aldrig i stripe.
  • DB-6: Riktig .card--portal-modifier, ej inline token-override.
  • DB-7: (a) .h-scene-* kanon; (b) --bg-scene-deep/--bg-scene tokeniseras — synka spegel mot global.css.

Gap-ytor (mockade på text)

  • TabellScreen: header/managed-rad-gradient → solid + accent-stripe (DB-8). Zon-stripe 11+ från Tailwind-röd → --danger (DB-1). Cup-bracket-score → ScoreBlock hero (DB-3). Tabbar 6→8 (DB-9).
  • InboxScreen: ${color}18 hex-append → color-mix … 6% (DB-1). Oläst-stripe behålls (sanktionerad).
  • SimSummaryScreen: Fortsätt-knapp bespoke → .btn .btn-primary. ScoreBlock-listan redan rätt.

Öppna flaggor till Opus

  • DB-7: --bg-scene-deep/--bg-scene finns i global.css men ej i colors_and_type-spegeln — spegeln behöver synkas (governance).
  • DB-1: glow-steget (35%) är det enda som kräver öga vid konvertering — Code bör flagga varje box-shadow för review, ej auto-konvertera.
  • DB-4: EkonomiTab stora saldo (sans-18/800 idag) → Georgia display-storlek eller Georgia-700 body? Föreslår display-sm (22px) för hero-saldo, 700 för inline.
