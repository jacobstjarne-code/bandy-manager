Bra audit. De tre avvikelserna är alla byggbara — här är design för var och en. Manager-portrait är det enda nya, övriga är regler.

1 · Manager-portrait i TränareTab

Återanvänd portrait-placeholder-systemet från trupp-polish, men manager-variant — inte spelararketyp. Manager har ingen position, så glyfen är initialer och gradienten är neutral leather-copper.

│  ╰────╯   Edsbyn                │

  • 54px cirkel (samma som modal-hero lg-storlek), border: 2px solid var(--border-dark)
  • Gradient: linear-gradient(135deg, var(--bg-leather) 0%, var(--accent-deep) 100%) — neutral, inte arketyp-färgad (manager är inte spelare)
  • Glyf: managerns initialer (för- + efternamn), Georgia 20px, rgba(255,255,255,0.9)
  • Veteran-ring återanvänds: 3+ säsonger vid klubben → subtle gold-ring, 6+ → legend-glow. Samma getPortraitPlaceholder-logik, bara variant: 'manager'.
  • Ingen status-dot (manager skadas inte) — men burnout-dot kan återanvända samma slot: danger-dot nere höger om burnout ≥ 70. Konsekvent med spelar-systemet.

Övergång till riktiga illustrationer: samma <Portrait>-wrapper, player.illustrationUrl blir manager.illustrationUrl. Code bygger placeholder nu, byter källa senare.

2 · PlayerRow-sparkline — fallback-regel (avvikelse 1)

Sparkline kräver minst 5 ratings i seasonHistory. Regel när datan är tom/tunn:

Datapunkter Render
≥ 5 Full sparkline
2–4 Sparkline med tillgängliga punkter, ingen area-fill (för få för att vara meningsfull)
0–1 Ingen sparkline. Visa bara CA-siffra + delta. Ingen tom ruta, ingen platshållare.

Tidigt på säsongen (omg 1–4) har spelare 0–1 ratings → sparkline saknas korrekt, inte en bugg. Code's hypotes stämmer: i verklig save sent på säsongen dyker den upp. Verifiera vid omg 8+.

3 · SeasonArcCard amber "TOPP"-label vid 66px (avvikelse 3)

Vid 66px höjd ryms inte labeln i bandet. Fix: flytta labeln utanför grafen som en mini-legend istället för inne i amber-zonen.

   [graf 66px med amber-zon till höger, ingen inline-label]
   ●  Topp-zon          ← legend-rad under grafen, 8px, amber-dot + text
  • Amber-zonen behålls som visuell bakgrund (den syns)
  • Labeln flyttas till en legend-rad under grafen: ● Topp-zon i 8px mono, amber-färg
  • Vid större höjder (om kortet expanderas) kan inline-label återkomma — men default-läget 66px använder legend-raden

Alternativt om Code vill behålla inline: rotera labeln vertikalt längs amber-zonens vänsterkant (90°, 7px). Men legend-raden är renare och läsbar.
