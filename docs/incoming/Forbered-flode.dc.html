Spela →

Taktik kan inte längre missas. Man kommer hit via stämpeln från elvan, inte via en flik. Samma tre-knapps-autofyll. Stämpeln "Spela →" startar matchen (RPS → SPELA).

1 · LINJÄR SEKVENS
  • subTabs för FÖRBERED tas bort. Ersätts av en läsbar två-stegs-indikator (① Uppställning · ② Taktik) — samma plats, men inte klickbar. Done = ✓, current = kopparunderstruken, pending = dämpad.
  • Progression via stämpeln: elvan → "Nästa: Taktik →" → taktik → "Spela →". Bakåt tillåts (rör inte committad elva); framåt bara via stämpel.
  • Valt framför alternativet: sekventiella skärmar hellre än att RPS-stripen visar FÖRBERED som två delsteg — tydligare "var är jag", mindre att tolka i stripen. (RPS-varianten kan byggas om du hellre vill ha den.)
2 · AUTOFYLL — ETT KLICK
  • De tre lägesknapparna blir fyll-knappar — var och en tillämpar sitt läge direkt. "Fyll bästa elvan" försvinner.
  • "Bäst för dagens match" = rekommenderad, koppar-fylld primär; Starkast / Mest utvilad = outline.
  • Samma mönster på både Uppställning och Taktik. Wiring: varje knapp → befintlig handleAutoFill(mode) med sitt läge.
3 · VINJETT (placering + passage)
  • Plats: före Uppställning, som fasens första andetag. Inte mellan elva och taktik (skulle bryta den täta 1→2-rytmen).
  • Passage: kort dwell → svep/tap på "Ta ut laget →". Ljusare pass-affordans, inte kopparstämpeln — den är för steg med val.
  • Bara första mötet mot varje klubb (samma krok som Berättaren-callbacken); filtrera managedClubId. Layout: full-bleed ortbild, vinjett-text, EN kontextrad + tränarcitat (ärver PreMatchContext-prioriteten).
DESIGN vs CODE

Design: steg-progressionen + tre-knapps-autofyllen + vinjett-ramen (ovan). Code: ta bort subTabs för FÖRBERED → linjär sekvens, koppla varje fyll-knapp till sitt läge, wira vinjett-triggern. Knapptexter låsta — "Bäst för dagens match" är din dom. Vinjett-texterna klara (Opus).
