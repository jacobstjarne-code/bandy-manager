PRIO 1

Burnouttaket

JA — slot mode=band burnout-ceiling
Motivriktning

Ett tömt omklädningsrum sent på kvällen — en enda kvarglömd tröja på bänken, ingen människa i bild.

Codex observation är kodbelagd: BurnoutMark renderar en ren portal-phasemark-div och läser därför som vilket beslut som helst. Men detta är karriärens mest personliga och irreversibla ögonblick — det måste bära visuell tyngd som ett vanligt kort inte ger.

band är rätt väl vägt val: tyngden ligger i övre halvan medan citat, helper och orsaksrad sitter kvar i fadezonen och skyddas. fullbleed skulle dränka den korta, viktiga texten; header vore för lätt för prio 1. Bandet får ge gravitet, inte konkurrera.
Code wire: bädda phasemark-diven i <IllustrationScene mode="band" name="burnout-ceiling"> — står tom tills .webp finns, inget hoppar.
PRIO 2

Klackbågen

JA — 2 slots mode=header ×2
Motiv · klack-tifo · dag 6

Ett halvfärdigt tifo hissas över en tom ståplatsläktare, Birger och gruppen underifrån.

Motiv · klack-konflikt · dag 11

Samma läktare, nu splittrad — två grupperingar vända från varandra kring ett generiskt supporterobjekt.

Två skilda event — supporter_tifo och supporter_conflict, olika producenter. "Ett gemensamt bildspråk med två motiv" betyder alltså två slots i två komponenter, inte en delad.

Samma mode är det som gör att de läser som en fortsättning — motivskiftet (byggt → splittrat) bär berättelsen. header upprepas rent över två feed-kort utan att dominera; band vore för tungt för återkommande event och skulle ge varje enskilt event mer vikt än det bär.
Code wire: två <IllustrationScene mode="header">, name klack-tifo / klack-konflikt — en per komponent.
PRIO 3

Bandygalan

NEJ — ingen slot guld-disciplin bevaras
Motivriktning

Ingen — guld-disciplinen är scenen; medaljen ska förbli den enda fyllda guldytan.

GalaScene har egen CSS och en medveten guld-disciplin: 🏆 är den enda fyllda guldytan i hela scenen. En bakgrundsbild inför en andra ljuspunkt som konkurrerar med medaljen och löser upp exakt den poängen. Codex "återhållsamt prisbord/scenmotiv" krockar med scenens egen mening.

Den typografiska scenen är redan komplett — bild är fel verktyg här. Om pipeline-symmetri ändå kräver en slot: enbart ett header-band ovanför gala-scene__header, aldrig i guldzonen. Men rekommendationen är nej.
Code wire: ingen slot. // alt (ej rekommenderad): mode="header" ovan gala-scene__header.
Ramar: token-baserat (--bg-portal, --ice, scen-paletten). Stripes/klammer = det etablerade språket. Scrim alltid — bilder lämnar aldrig text naken.
