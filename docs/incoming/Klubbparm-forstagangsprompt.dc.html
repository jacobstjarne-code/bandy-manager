Visad: första Portal-besöket, direkt efter Tillträdets "Första omgången". Copy (Opus) låst. Byggd på DS Overlay-mönstret — samma som KlubbparmOverlay.

FÖR CODE — WIRING
  • Trigger: första gången Portalen renderas efter onboardingComplete === true, och endast om klubbparmOfferSeen !== true. Visa en gång per save.
  • Skal: återanvänd Overlay-primitiven (centrerad, rgba(0,0,0,.6), ingen blur, maxWidth 340–380). Läder-header-band, coach-framing = samma mönster som Tillträdets CoachFraming.
  • Ja: sätt klubbparmOfferSeen = true (persist) och öppna befintliga KlubbparmOverlay direkt — bygg inget nytt innehåll.
  • Nej: sätt klubbparmOfferSeen = true (persist), stäng. Pärmen ligger kvar i menyn oförändrad.
  • Coach: namn/monogram från game.assistantCoach (som i TilltradeScreen), inte hårdkodat "MM".
REGELN STÅR KVAR

Erbjudandet flyttar ingenting. Pärmen är spelets enda instruktion och förblir en menypost som låser upp kapitel i takt. Modalen är en inbjudan vid första besöket — "Nej" är ett fullgott, jämnstort svar, aldrig en återvändsgränd.

ÖPPEN FRÅGA TILL CODE (EJ DESIGN)

Finns ett tvingande onboarding-steg som ändå pushar pärmen efter introt (kolla onboarding-migrationstesterna)? Om ja — det är det som mjukas upp till detta erbjudande. Om nej — dippen var en gissad övergång och detta är hela åtgärden.
